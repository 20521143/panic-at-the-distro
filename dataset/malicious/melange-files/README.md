# Melange Files for Wolfi APK Construction

This directory contains a collection of Melange YAML files, each describing the metadata and build instructions for Dataset #2. These files are utilized to construct Wolfi APKs, which are then used for security analysis and research within this project.

## Purpose

- **Melange Files**: Define package metadata, dependencies, and build steps for generating Wolfi APKs.
- **Wolfi APKs**: Containerized application packages built from these Melange files, enabling consistent and reproducible analysis of potentially malicious software.

## Usage

Researchers can use these Melange files to: Reproduce the APK build process for each sample.
